# デグレード防止ナレッジ & UI設計ルール (Knowledge & Anti-Regression Rules)

本ドキュメントは、過去に発生した重大なUI・UX不具合の再発（デグレード）を防ぐための設計ルールと実装の知見をまとめたものです。
今後のUI改修やスタイル変更を行う際は、必ず本ドキュメントのルールを遵守してください。

---

## 1. 発生した不具合と対策

### ① モバイル端末での日付入力不可・キーボード不発
- **問題**: ネイティブの `<input type="date">` を使用すると、一部のスマートフォンやWebView環境においてキーボードが表示されず、かつネイティブピッカーも起動しないため日付の入力・変更が不可能になった。
- **恒久対策**:
  - ネイティブの `type="date"` に依存せず、JavaScriptによる**カスタムカレンダーピッカー（`js/calendar.js`）**で日付選択を行う。
  - スマホの小さな画面でも操作しやすいよう、「今日」「明日」「明後日」「1週間後」「今週末」の**クイック日付タグ**および前日・翌日ステップボタン（`◀` / `▶`）を常に併設し、**指先タップのみで100%完結するUI**を維持すること。

### ② スマホ表示時のカレンダー下部見切れ・後続カードへの潜り込み
- **問題**: スマートフォンでカレンダーを開いた際、カレンダーの下部（25日〜31日や「今日に戻る」ボタン）が後続の結果カードの下に潜り込んで見えなくなり、タップ不能になった。
- **根本原因**:
  1. **スタッキングコンテキスト（重なり順）の分離**:
     入力パネルの親カード（`.glass-card`）に `backdrop-filter: blur(...)` が適用されているため、ブラウザ仕様により新しいスタッキングコンテキストが生成される。このため、カレンダー要素にどれだけ大きな `z-index` を指定しても、親要素（入力セクション）の外側に出ると後続の結果セクション（`#results`）の下に隠れてしまう。
  2. **スマートフォンの画面高の限界**:
     縦画面のスマートフォンでは、入力欄の直下にカレンダーを絶対配置（`position: absolute`）すると画面下端を突き抜けやすい。
- **恒久対策**:
  1. **モバイル時は画面中央モーダル固定表示（`position: fixed`）**:
     画面幅 640px 未満では、カレンダーをドロップダウンではなく**画面中央に固定配置されるモーダル（`position: fixed; top: 50%; left: 50%; transform: translate(-50%, -50%)`）**として展開し、背面に半透明の黒幕（`.cal-backdrop`）を表示する。これにより画面スクロール位置に依存せず、常に画面内に月末日とフッターボタンが100%収まる。
  2. **セクション単位の z-index 階層制御**:
     入力セクションに `relative z-20`、結果セクションに `relative z-10` を必ず付与し、セクション間の重なり順を固定する。
  3. **PC表示との両立**:
     画面幅 640px 以上のPC環境では、入力欄直下に自然に展開するドロップダウン（`position: absolute; top: calc(100% + 8px)`）スタイルを維持する。

## 2. 変更時の必須検証チェックリスト（回帰テスト基準）

UIやCSS、スクリプトの修正を行った後は、コミット・マージ前に以下の項目を必ずブラウザ（実機または開発者ツール）で検証してください。

- [ ] **スマホ幅（375px〜390px）でのカレンダー展開チェック**:
  - カレンダーを開いた際、画面中央にモーダルとして表示され、背後に黒幕（バックドロップ）が出ること。
  - 1日〜月末日（31日など）まですべての日付セルが表示されていること。
  - フッターの「今日に戻る」「閉じる」ボタンが画面外や他カードの裏に隠れていないこと。
  - バックドロップのタップでカレンダーがスムーズに閉じること。
- [ ] **クイック日付タグの動作チェック**:
  - 「今日」「明日」「明後日」「1週間後」「今週末」を押した際、正しく日付が切り替わり、ボタンのアクティブ状態が連動すること。
- [ ] **前日・翌日ボタン（◀ / ▶）の動作チェック**:
  - ボタンを押して1日ずつ日付が増減すること。
- [ ] **PC表示（1024px以上）でのレイアウトチェック**:
  - 入力バーの直下にカレンダーがドロップダウンし、横はみ出しがないこと。
- [ ] **コンソールエラーの非発生**:
  - 各種操作時に JavaScript エラー（赤い警告）が一切出力されていないこと。
